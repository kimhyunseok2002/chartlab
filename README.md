# ChartLab — 무료 차트 분석 도구

트레이딩뷰 대신 쓰는 개인용 차트 분석 도구입니다. 설치할 것 없이 Python만 있으면 됩니다.

## 실행

- **`start.bat` 더블클릭** → 브라우저가 `http://127.0.0.1:8777`로 열립니다. 검은 창(서버)을 닫으면 종료됩니다.
- 코인만 볼 거면 `index.html`을 바로 열어도 됩니다. 주식·지수는 서버가 필요합니다.
- 서버는 내 PC(127.0.0.1)에서만 열리고 외부에서는 접속할 수 없습니다.

### 웹 버전 (Vercel)

- 주소: **https://chartlab-roan.vercel.app** — 설치 없이 폰·다른 PC에서도 열립니다.
- GitHub `kimhyunseok2002/chartlab`(비공개) main 브랜치에 push하면 자동 배포됩니다.
- 웹 버전은 `api/` 서버 함수가 주식 데이터와 업비트 시세를 대신 받아 옵니다 (업비트는 웹사이트에서 브라우저로 직접 부르는 요청을 막기 때문).
- 드로잉·설정은 사이트마다 따로 저장됩니다. 로컬 버전과 옮기려면 설정 → 백업 내보내기/가져오기를 쓰세요.

## 드로잉 도구 (84종)

- **선**: 추세선, 레이, 정보선, 확장선, 추세 각도, 수평선, 수평 레이, 수직선, 십자선, 평행 채널, 회귀 추세, 평평한 상단/하단, 분리 채널
- **피치포크**: 앤드류, 쉬프, 수정 쉬프
- **피보나치**: 되돌림, 추세 기반 확장, 채널, 시간대, 속도저항 팬, 추세 기반 시간, 원, 나선, 속도저항 호, 쐐기, 피치팬
- **간(Gann)**: 간 박스, 간 스퀘어, 간 팬
- **패턴**: XABCD, 사이퍼, 헤드앤숄더, ABCD, 삼각형, 쓰리 드라이브
- **엘리엇**: 충격파(12345), 조정파(ABC), 삼각파(ABCDE), 이중 조합(WXY), 삼중 조합(WXYXZ)
- **사이클**: 사이클 라인, 타임 사이클, 사인 라인
- **예측·측정**: 롱/숏 포지션(손익비·수량·목표/손절 도달 표시), 예측, 바 패턴, 고스트 피드, 기간/가격/기간·가격 범위, 앵커드 VWAP, 고정 범위·앵커드 볼륨 프로파일
- **도형**: 브러시, 하이라이터, 화살표 마커, 화살표, 위/아래/왼쪽/오른쪽 화살표 표시, 사각형, 회전 사각형, 경로, 원, 타원, 폴리라인, 삼각형, 호, 곡선, 이중 곡선
- **주석**: 텍스트, 고정 텍스트, 노트, 고정 노트, 콜아웃, 코멘트, 가격 라벨, 가격 노트, 사인포스트, 깃발, 이모지
- **보조**: 측정(Shift+드래그), 확대(영역 드래그), 지우개, 자석(약/강, Ctrl로 일시 전환), 그리기 모드 유지, 전체 잠금·숨기기, 객체 트리

드로잉은 지표 창(RSI 등)에도 그릴 수 있고, 시간·가격 기준으로 저장돼서 주기를 바꿔도 같은 자리에 있습니다.

## 지표 (26종, 개수 제한 없음)

- **자동 추세선**: 스윙 고점·저점을 이어 지지/저항 추세선을 자동으로 그림. 두 접점 사이에서 종가가 넘지 않은 선만 채택하고, 종가가 뚫으면 점선 + 돌파·이탈 표시(알림 선택). ⚙ → "드로잉으로 복사"로 일반 추세선으로 만들어 직접 수정 가능
- **이동평균**: MA(SMA·EMA·WMA·HMA·VWMA·RMA·DEMA·TEMA), 다중 이동평균(5·20·60·120 등 6개), 볼린저 밴드, 엔벨로프, 일목균형표, 슈퍼트렌드, 파라볼릭 SAR, DMI/ADX
- **거래량**: 거래량(+이동평균, 차트 위/별도 창), 매물대(VPVR, POC·밸류 에어리어), VWAP(일·주·월 + 밴드), OBV, MFI, CMF, A/D, PVT, 거래량 오실레이터
- **오실레이터**: RSI(이동평균·볼린저·다이버전스 표시), MACD, 스토캐스틱, 스토캐스틱 RSI, CCI, 윌리엄스 %R, 모멘텀, ATR

## 그 밖의 기능

- 멀티 차트 레이아웃(1·2·3·4분할) + 크로스헤어 시간 동기화, 같은 종목 드로잉 자동 공유
- 바 리플레이(분봉 포함, 0.5~20봉/초) — 연습 매매용
- 가격 알림(교차·상향·하향 돌파, 브라우저 알림 + 소리) — 페이지가 열려 있는 동안 동작
- 관심종목(실시간 시세), 캔들/할로우/하이킨아시/바/라인/영역 차트, 로그 스케일
- 다크/라이트 테마, 국내식(상승 빨강) / 해외식(상승 초록) 캔들 색
- 스크린샷 PNG 저장, 실행 취소/다시 실행, 드로잉 복사/붙여넣기
- 모든 설정·드로잉·지표는 브라우저에 자동 저장. **설정 → 백업 내보내기/가져오기**로 다른 PC로 옮길 수 있음

단축키는 화면 오른쪽 위 **?** 버튼에 있습니다.

## 알아둘 점

- 트레이딩뷰 도구 목록 중 Projection, Inside Pitchfork, 표(Table), 이미지 넣기는 없습니다.
- 주식 시세는 무료 공개 API(야후 파이낸스)라 지연이 있고, 야후가 막으면 일시적으로 안 될 수 있습니다.
- 브라우저 저장소(localStorage)를 지우면 드로잉도 지워지니 가끔 백업하세요.
